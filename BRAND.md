# Aperyn brand system

## Identity

The mark is **Nym**, Aperyn's original signal-moth mascot. Its mirrored wings form a compact A-like silhouette while the raised antennae carry the product's signal theme. It is unrelated to the Ollama llama, OpenAI swirl, DeepSeek whale, Anthropic starburst, GitHub Octocat, Hugging Face face, or other vendor marks. Vendor marks may identify catalogue entries only.

The canonical SVG uses a 64×64 viewBox, a white silhouette, and dark facial negative space. The same geometry is rendered onto a dark-backed tile for 16, 32, 192, and 512 pixel contexts.

## Signal Glass

Version 1.27.1 calls its visual language **Signal Glass**. Surfaces use controlled translucency, adaptive hairlines, inner highlights, restrained shadows, and soft accent refraction. Text and controls retain strong backing contrast.

Agent extends the same system with a three-part working canvas: saved-task rail, conversation timeline, and compact live-activity panel. Its hexagonal pulse icon belongs to the same 1.8-stroke monochrome navigation family. The interface was designed for Aperyn and does not reproduce OpenCode's WebUI structure or visual assets.

Per-user modes are Off, Subtle, and Full. Mobile Full uses a lower blur budget. Unsupported browsers receive solid fallbacks; reduced-motion preferences disable nonessential motion.

## Tokens

Selection/focus use `--accent`, `--accent-rgb`, `--accent-soft`, `--accent-border`, and `--accent-glow`. Surfaces use `--bg`, `--panel`, `--panel-2`, and `--panel-3`. Red, amber, and green are reserved for error, warning, and healthy status semantics.

## Voice

Use direct operational language. Do not borrow another product's slogans, DOM vocabulary, or visual metaphors.

## Wordmark

The product name is **Aperyn**. Primary branded surfaces place the smaller descriptor **“An Ollama model editor and chat”** beneath the wordmark. “Ollama” is descriptive there and is not used as Aperyn's application mark.

Nym is the selected product mark and the default assistant name. The interface may render six expression states—idle, chatting, thinking, coding, approval, and error—without altering the wing/body silhouette. Motion is restrained, state-driven, and disabled by reduced-motion preferences.

Navigation uses an original eight-icon functional family on a 24-unit grid. Every mark uses a 1.8-unit monochrome stroke with rounded caps and joins; selected state comes from the user's accent rather than a separate icon style.
